# Advanced AI Demand Forecasting

## Project Description
Advanced AI Demand Forecasting is a full stack web application used to upload datasets, analyze sales data, and generate future demand forecasting using Machine Learning.

---

# Technologies Used

## Backend
- FastAPI
- Python
- MySQL
- SQLAlchemy
- Scikit-Learn
- JWT Authentication

## Frontend
- React JS
- Tailwind CSS
- Axios
- React Router DOM

---

# Features

- User Registration
- User Login Authentication
- Dataset Upload
- CSV/Excel File Handling
- AI Demand Forecast Prediction
- Dashboard Analytics
- Reports Generation
- REST API Integration

# Backend Setup

## Step 1

```bash
cd backend
```

## Step 2

```bash
pip install -r requirements.txt
```

## Step 3

```bash
python run.py
```

Backend Running URL:

```txt
http://127.0.0.1:8000
```

Swagger Documentation:

```txt
http://127.0.0.1:8000/docs
```

---

# Frontend Setup

## Step 1

```bash
cd frontend
```

## Step 2

```bash
npm install
```

## Step 3

```bash
npm run dev
```

Frontend Running URL:

```txt
http://localhost:5173
```
